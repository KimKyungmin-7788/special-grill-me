# special-grill-me

계획, 결정, 아이디어를 한 번에 한 질문씩 집요하게 인터뷰해서 다듬고, 그 결과를 개발 도구(Claude Code, Codex)에 넘길 문서로 만들어 주는 Claude 스킬입니다. 채팅창에서 쓰도록 만들었습니다. 말로만 묻지 않고, 사용자가 머릿속에 그리고 있는 모습을 이미지나 동영상으로 먼저 받아 같은 그림을 보고 시작합니다.

A Claude skill that grills you about a plan one question at a time, asks early for sketches, screenshots or videos of what you picture, and turns the decisions into a PRD or a handoff set (with reference images) for Claude Code and Codex. If an educational app idea is not settled yet, it first pitches a few distinct concepts. The skill is written in Korean.

## 무엇을 하나요

1. **맥락 자료 받기**: 첫 질문에서 손그림, 비슷한 앱 화면 캡처, 수업 장면 사진이나 영상을 요청합니다. 받은 자료는 따를 것, 분위기만 참고할 것, 따르지 않을 것으로 나눠 되짚고, 맞는지 확인받은 내용은 다시 묻지 않습니다. 학생 얼굴이나 이름은 가려서 올리도록 안내합니다.
2. **아이디어 발산** (만들 것이 아직 정해지지 않았을 때만): 대상 학생의 수준과 특성을 먼저 확인하고, 서로 다른 접근의 컨셉 3~4개를 선택지로 보여 줍니다. 컨셉마다 만들기 부담과 학생 정보 저장 여부가 표시됩니다.
3. **인터뷰**: 한 번에 질문 하나만 묻습니다. 질문마다 선택지 2~4개를 주고 추천안을 첫 번째에 둡니다. 다른 결정을 가장 많이 막고 있는 질문부터 묻고, 화면이나 분위기처럼 눈으로 봐야 정해지는 부분에서는 그 부분의 자료를 한 번 더 요청합니다. 질문이 8개쯤 쌓이면 계속할지, 남은 것은 추천안으로 정할지 묻습니다.
4. **정리와 확인**: 더 물을 것이 없으면 정해진 결정을 목록으로 보여 주고 맞는지 확인받습니다.
5. **산출물**: 요약만, PRD 한 장, 개발 인계 세트(앱, 웹, 도구처럼 개발할 대상일 때) 가운데 하나를 만듭니다. 개발할 대상이면 무엇을 만들지 인터뷰 앞쪽에서 미리 묻습니다.

찾아볼 수 있는 사실은 스킬이 직접 찾고, 결정은 사용자가 합니다. 결정 기록에는 각 결정을 어떻게 정했는지가 남습니다(추천안 선택, 다른 선택지, 직접 입력, 자료로 확인, 추천안에 맡김).

## 개발 인계 세트

인터뷰 결과를 개발 도구가 실제로 읽는 자리에 나눠 담습니다.

| 산출물 | 담는 것 |
|---|---|
| PRD.md | 무엇을, 왜, 누구를 위해 만드는지와 성공 기준 |
| AGENTS.md | 매번 지킬 규칙, 기술 스택, 문서 위치 |
| CLAUDE.md | AGENTS.md를 불러오는 한 줄과 Claude Code 전용 규칙 |
| DEVELOPMENT.md | 배포와 운영, 데이터, 개발 단계와 단계별 완료 확인 방법 |
| DESIGN.md | 화면 규칙, 분위기, 화면 목록, 참고 이미지마다 따를 것과 따르지 말 것 |
| references/ | 인터뷰에서 받은 참고 이미지(학생을 알아볼 수 없는 것만) |
| 시작 프롬프트 | 개발 도구에 처음 붙여넣는 글 |

- 문서는 폴더째 zip 하나로 전달합니다.
- 시작 프롬프트는 파일이 아니라 채팅에 코드박스로 제시합니다. 복사해서 개발 도구에 바로 붙여넣으면 됩니다.
- 새 프로젝트면 압축을 푼 폴더가 그대로 프로젝트 폴더가 됩니다.
- 기존 프로젝트에 기능을 추가하는 경우에는 기존 지침 파일을 덮어쓰지 않도록, 합칠 조각(AGENTS-add.md)만 만듭니다.
- 인터뷰에서 정하지 않은 것은 지어내지 않습니다. 실행 명령어처럼 프로젝트를 세팅해야 알 수 있는 칸은 비워 두고 개발 도구가 채우게 합니다.

## 설치

**Claude 앱(채팅)** — `skills/special-grill-me` 폴더를 zip으로 묶어 스킬로 올립니다. zip을 열었을 때 맨 위에 `special-grill-me` 폴더가 있어야 합니다.

**Claude Code** — `skills/special-grill-me` 폴더를 `~/.claude/skills/` 아래에 복사합니다.

SKILL.md 하나만 가져가면 안 됩니다. 인계 세트를 만들 때 `references/handoff-templates.md`를 읽기 때문에 폴더째로 설치해야 합니다.

## 사용법

채팅에서 `/special-grill-me`라고 입력하거나 "이 계획 grill me 해줘"처럼 말한 뒤, 다듬고 싶은 계획을 설명합니다. 아직 아이디어가 없으면 "수업에서 이런 게 불편한데 앱으로 만들고 싶어"처럼 문제 상황만 말해도 됩니다. 그리고 있는 화면의 손그림이나 참고할 앱 캡처가 있으면 처음부터 함께 올리면 더 빨라집니다.

이 스킬은 아이디어를 내는 일까지 맡으므로, 같은 일을 하는 다른 스킬(원본 grill-me, 앱 아이디어 생성 스킬 등)이 함께 설치되어 있으면 꺼 두는 것이 좋습니다. 그래야 어느 스킬이 실행될지 헷갈리지 않습니다.

## 폴더 구성

```
skills/special-grill-me/
  SKILL.md                         맥락 자료 요청, 아이디어 발산, 인터뷰 진행과 마무리 규칙
  references/handoff-templates.md  인계 문서 템플릿과 시작 프롬프트 틀
```
